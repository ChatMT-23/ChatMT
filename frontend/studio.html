Choose a colour

Rainbow — pick one to start

With a standard code

The nine colours written in standards/colour-meanings.json.

Without a standard code

Deliberately left out of the standard. ChatMT reports that it has no rule for them instead of guessing one.

Five colours are encouraged. Magenta carries the same meaning as indigo, and purple the same as violet, so they are encouraged too. Red and yellow are questioned: choosing one asks a question, and the answer changes the profile.

The standard code asks this question before accepting the colour. An absent reason is personal in nature: it makes the profile not friendly and delays the answers, while the preference itself is not stored until the question is answered.

Tip: if ChatMT asked “why”, just type the reason here — it is sent as your answer.

10

A red or yellow background

on request · cogent reason required

Backgrounds tending towards red or yellow are suggested only when you ask for them and give a cogent reason. When you ask, the app asks immediately why. A reason that is personal, or no reason at all, activates the unfriendly mood and stores the profile for the next engagement.

Correction

a separate record · never automatic

Something wrong with this answer?

A correction is stored as a separate record (memory category D). It never changes the standard code by itself: the standard can only be changed by an explicit, documented decision.
